| Evidencia o criterio | Pregunta clínica | Recomendación que debe consultarse |
|---|---|---|
| PVS1 | ¿La variante realmente produce pérdida de función? | [ClinGen PVS1: variantes con pérdida de función](https://pubmed.ncbi.nlm.nih.gov/30192042/) |
| PS2 / PM6 | ¿La variante es de novo y qué tan bien está confirmada la filiación? | [ClinGen PS2/PM6](https://www.clinicalgenome.org/curation-activities/variant-pathogenicity/documents/) |
| PM3 | ¿Las variantes están en trans en una enfermedad autosómica recesiva? | [ClinGen PM3](https://clinicalgenome.org/docs/?doc-type=supporting-documents) |
| PM2 | ¿La ausencia o rareza en población aporta evidencia y con qué fuerza? | [ClinGen PM2](https://clinicalgenome.org/docs/?doc-type=supporting-documents) |
| PP1 / BS4 | ¿Existe cosegregación o falta de segregación familiar? | [ClinGen Variant Classification Guidance](https://clinicalgenome.org/tools/clingen-variant-classification-guidance/) |
| PP3 / BP4 | ¿Cómo utilizar predictores computacionales sin sobrecontar evidencia? | [ClinGen Variant Classification Guidance](https://clinicalgenome.org/tools/clingen-variant-classification-guidance/) |
| PS3 / BS3 | ¿El ensayo funcional está suficientemente validado? | [ClinGen Variant Classification Guidance](https://clinicalgenome.org/tools/clingen-variant-classification-guidance/) |
| BA1 / BS1 | ¿La frecuencia poblacional es incompatible con la enfermedad? | [ClinGen Variant Classification Guidance](https://clinicalgenome.org/tools/clingen-variant-classification-guidance/) |
| PP5 / BP6 | ¿Debe utilizarse la clasificación de otra fuente como evidencia? | [ClinGen Variant Classification Guidance](https://clinicalgenome.org/tools/clingen-variant-classification-guidance/) |
