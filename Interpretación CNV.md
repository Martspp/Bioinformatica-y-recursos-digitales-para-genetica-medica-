# Guía
Tabla para decidir entre guía de SNV y guía de CNV
ACGS 2024 recomienda, en ausencia de especificaciones por gen o enfermedad, emplear la guía de CNV para CNV constitucionales, pero manejar las deleciones y duplicaciones intragénicas bajo el marco de variantes de secuencia cuando su efecto debe evaluarse como pérdida de función

| Hallazgo | Guía que debe aplicarse principalmente | Motivo |
|---|---|---|
| Deleción multigénica | [ACMG/ClinGen CNV 2020](https://pubmed.ncbi.nlm.nih.gov/31690835/) | Se evalúan contenido génico, haploinsuficiencia, región crítica, población, casos y herencia |
| Duplicación multigénica | [ACMG/ClinGen CNV 2020](https://pubmed.ncbi.nlm.nih.gov/31690835/) | Se aplica el sistema de puntuación específico para ganancias |
| Deleción completa de un solo gen | Evaluar ACMG/AMP/PVS1 y guía CNV según el contexto | Puede actuar como variante de pérdida de función del gen |
| Deleción de uno o varios exones | [ACMG/AMP 2015](https://pubmed.ncbi.nlm.nih.gov/25741868/) + [ClinGen PVS1](https://pubmed.ncbi.nlm.nih.gov/30192042/) | Debe determinarse marco de lectura, transcrito, NMD y mecanismo de enfermedad |
| Duplicación intragénica | ACMG/AMP/PVS1 con cautela | Debe conocerse orientación, localización y efecto sobre el marco de lectura |
| CNV que incluye una región de dosificación conocida | ACMG/ClinGen CNV 2020 | La sensibilidad a haploinsuficiencia o triplosensibilidad puede aportar evidencia fuerte |
| CNV detectada por WGS | ACMG/ClinGen CNV 2020 + [guía técnica ACGS para WGS](https://www.acgs.uk.com/media/12946/guidelines-for-cnv-and-sv-analysis-from-wgs-data-final-v12.pdf) | Primero debe evaluarse la validez técnica y después la relevancia clínica |
